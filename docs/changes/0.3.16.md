# 栏量 0.3.16 契约：悬停展开时也能直接按 Esc 收起（参照栏历）

> **已取消（老板 01:33 NY）**：保持 0.3.15 的做法，悬停展开不抢焦点，点一下面板后按 Esc 收起。不推 wip-0.3.16，不打 v0.3.16。

需求：老板 2026-11-27 01:32 NY 实机反馈。PM 01:33 NY 定稿。基线 master（v0.3.15 bba8e86）。分支 `wip-0.3.16`。不出样稿（只改键盘焦点，没有界面变化）。

## 问题
0.3.15 按契约让悬停预览不抢键盘焦点，所以鼠标指向菜单栏图标、面板展开后，必须先点一下面板，Esc 才生效。栏历悬停展开时调用 `calendarWindow.show()`（`electron/main.js:766`），窗口一出来就拿到键盘焦点，直接 Esc 就能收起。0.3.16 照栏历改。

## 规则
1. 悬停预览（`preview`）展开时，也调用 `panel.makeKey()`，和固定面板（`pinned`）一样。只调 `makeKey()`，不调 `NSApp.activate`（PM 01:33 NY）。
2. 面板是不激活应用的类型（nonactivating），拿到键盘焦点也不切走前台应用；面板收起后，原来的应用照常接收键盘。
3. 0.3.15 的 Esc 分层规则全部不变：设置页回主页，主页收起，带修饰键的 Esc 不处理，收起后下次打开停在主页。
4. 照旧不加任何全局或本地键盘监听，不申请辅助功能或输入监控权限。

## 验收
1. 单测：0.3.15 的 Esc 分层单测保持全绿。
2. CI：`--debug-esc-lifecycle` 里把 `previewNoKey` 改成 `previewKey=true`，再加一步「悬停预览时按 Esc 能收起」，以 CI 输出 `DEBUG_ESC_LIFECYCLE ok` 为准，不加截图。
3. 老板 Mac 实机走查：
   - 鼠标指向菜单栏图标，面板展开后不点它，直接按 Esc，面板收起；
   - 面板收起后，原来在用的应用照常能打字；
   - 点图标打开面板，进设置，按 Esc 回主页，再按 Esc 收起；
   - 收起后再打开，停在主页。
