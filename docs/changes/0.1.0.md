## 2. Codex
### 2.1 凭证 `~/.codex/auth.json`（有 `CODEX_HOME` 环境变量时用它）
```json
{"OPENAI_API_KEY": null,
 "tokens": {"id_token": "eyJ…", "access_token": "eyJ…", "refresh_token": "…", "account_id": "a1b2c3"},
 "last_refresh": "2026-11-24T10:00:00Z"}
```
- 没有 `tokens`、只有 `OPENAI_API_KEY` → API Key 账号（见状态表）。
### 2.2 账号和订阅：解码 `tokens.id_token`（JWT 第二段 base64url，不验签）
```json
{"email": "allen@example.com",
 "https://api.openai.com/auth": {"chatgpt_plan_type": "pro",
   "chatgpt_subscription_active_until": "2026-12-12T08:00:00+00:00", "chatgpt_account_id": "a1b2c3"}}
```
- `chatgpt_subscription_active_until` 可能是 ISO 字符串或秒级数字，两种都要认；缺失就不显示有效期行。
- 套餐显示名（小写后匹配，先精确后包含）：`free`→Free，`plus`→Plus，`prolite`/`pro-lite`→Pro 100，`pro`→Pro 200，`promax`/`pro-max`→Pro 500，含 `team`→Team，含 `business`→Business，含 `enterprise`→Enterprise，含 `edu`→Edu，其它原样。
### 2.3 额度 `GET https://chatgpt.com/backend-api/wham/usage`
头：`Authorization: Bearer <access_token>`，`Accept: application/json`，`ChatGPT-Account-Id: <tokens.account_id>`（有才加），`User-Agent: LanLiang/<版本>`。
```json
{"plan_type": "pro",
 "rate_limit": {"primary_window":   {"used_percent": 23, "reset_at": 1764655200, "limit_window_seconds": 604800},
                "secondary_window": null}}
```
- **按 `limit_window_seconds` 认窗口**：18000 = 5 小时，604800 = 周；不看是 primary 还是 secondary。剩余% = 100 − used_percent，四舍五入取整，夹在 0–100。`reset_at` 是 Unix 秒。
- `used_percent` 可能是小数或字符串数字，都要认。
- 401/403 → 登录过期态。
### 2.4 官方 Token（多端）`GET https://chatgpt.com/backend-api/wham/profiles/me`（同样的头）
```json
{"stats": {"daily_usage_buckets": [{"start_date": "2026-11-23", "tokens": 304000000}, {"start_date": "2026-11-24", "tokens": 52000000}]}}
```
### 2.5 本机 Token：扫 `~/.codex/sessions/**/*.jsonl` 和 `~/.codex/archived_sessions/**/*.jsonl`
每行一个 JSON，只认这种：
```json
{"timestamp":"2026-11-24T01:00:00Z","type":"event_msg","payload":{"type":"token_count","info":{"last_token_usage":{"input_tokens":5200,"cached_input_tokens":4100,"output_tokens":310,"reasoning_output_tokens":120,"total_tokens":5510}}}}
```
- 每条累加 `last_token_usage.total_tokens`（缺失时 = input_tokens + output_tokens），按 `timestamp` 换成本地日期归日。不用 `total_token_usage`（那是会话累计，会重复算）。`info` 为 null 的跳过；坏行跳过不报错。
- 扫描放后台线程；按文件修改时间增量，已扫过且没变的文件不重读。

## 3. Gemini（Google Antigravity 登录）
### 3.1 凭证读取顺序
1. 文件 `~/.gemini/jetski-standalone-oauth-token`
2. 文件 `~/.gemini/antigravity-cli/antigravity-oauth-token`
3. 钥匙串通用密码：service `gemini`，account `antigravity`；值以 `go-keyring-base64:` 开头时去掉前缀再 base64 解码。
内容：
```json
{"token": {"access_token": "ya29…", "token_type": "Bearer", "refresh_token": "1//0g…", "expiry": "2026-11-24T20:30:00Z"}, "auth_method": "oauth", "id_token": "eyJ…"}
```
- 文件读到就不碰钥匙串（不弹授权框）。
- `expiry` 已过或接口返回 401：用 refresh_token 在内存里换新令牌（`POST https://oauth2.googleapis.com/token`，grant_type=refresh_token，client_id/client_secret 用 Antigravity 桌面端内置的公开值，见 mind 盒子 `/home/box/mind-workspace/projects/lan-liang/research/antigravity-oauth-client.md`，不贴进群），不写回任何地方。**换新失败才**提示「Gemini 登录已过期，打开一次 Antigravity 后再刷新」（PM 15:17 ET 最终决定）。
### 3.2 套餐 `POST https://daily-cloudcode-pa.googleapis.com/v1internal:loadCodeAssist`
头：`Authorization: Bearer <access_token>`，`Content-Type: application/json`，`User-Agent: antigravity/<版本> darwin/<arm64|x64>`。版本取 `/Applications/Antigravity.app/Contents/Info.plist` 的 `CFBundleShortVersionString`，读不到或低于 2.25.0 就用 2.25.0。
请求体：`{"metadata":{"ideName":"antigravity","ideType":"ANTIGRAVITY","ideVersion":"<版本>","pluginType":"GEMINI","updateChannel":"stable"},"mode":"FULL_ELIGIBILITY_CHECK"}`
```json
{"cloudaicompanionProject": "aicode-consumers",
 "currentTier": {"id": "free-tier", "name": "Free"},
 "paidTier": {"id": "g1-pro-tier", "name": "Google AI Pro"}}
```
- 套餐显示：`paidTier` 优先，否则 `currentTier`；有 `name` 用 name，没有就按 id：`g1-pro-tier`→Pro，`g1-ultra-tier`→Ultra，`free-tier`→Free，`standard-tier`→Standard，其它原样。
- `cloudaicompanionProject` 可能是字符串，也可能是 `{"id": "…"}`，都要认。没有 project 时不做 onboarding，直接显示「额度获取失败」。
- 邮箱：`id_token` 的 `email`；没有就 `GET https://www.googleapis.com/oauth2/v2/userinfo` 取 `email`。
### 3.3 额度 `POST https://daily-cloudcode-pa.googleapis.com/v1internal:retrieveUserQuotaSummary`
头：`Authorization`，`User-Agent: antigravity/hub/<版本> (aidev_client; os_type=darwin; arch=<arm64|x64>)`。请求体：`{"project":"<project>"}`
```json
{"groups": [
  {"displayName": "Gemini Models", "buckets": [
    {"bucketId": "gemini-weekly", "window": "weekly", "remainingFraction": 0.44, "resetTime": "2026-11-28T01:43:47Z"},
    {"bucketId": "gemini-5h", "window": "5h", "remainingFraction": 0.64, "resetTime": "2026-11-24T22:54:47Z"}]},
  {"displayName": "Claude and GPT models", "buckets": [
    {"bucketId": "3p-weekly", "window": "weekly", "remainingFraction": 1, "resetTime": "2026-11-28T01:30:47Z"}]}]}
```
- 只取 Gemini 家族：bucketId 是 `gemini-weekly`/`gemini:weekly`（周）、`gemini-5h`/`gemini:5h`（5 小时）。`3p-*`、`claude:*`、`argon` 等一律忽略。
- 剩余% = remainingFraction × 100 取整；**`remainingFraction` 缺失 = 0%**（接口不发 0 值）。
