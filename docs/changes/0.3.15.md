# 栏量 0.3.15 契约：按 Esc 收起面板（参照栏历）

需求：老板 2026-11-27 00:52 NY。基线 master 9ef3fd9。分支 `wip-0.3.15`。不出样稿（只改键盘行为，没有界面变化）。

## 现状
栏量只有一个面板（`FloatingPanel`）。设置不是单独的窗口，而是面板里的一页（`model.showsSettings`）。老板说的「主窗口」和「设置窗口」，指的就是这两页。

## 规则（和栏历 `electron/main.js:449-468` 一样，由里往外一层一层退）
1. 设置页上按 Esc：回到主页（相当于点「返回」），面板不收起。
2. 主页上按 Esc：收起面板（走 `hidePanel()`，和点面板外面一样）。
3. 设置页里有正在显示的悬停气泡或选中的柱子时，Esc 也直接回主页，不另设一层。
4. 只认不带修饰键的 Esc（keyCode 53）。⌘ / ⌥ / ⌃ / ⇧ 加 Esc 不处理。
5. 面板收起后，下次打开停在主页（现有行为不变）。

## 什么时候能收到 Esc
- 点击菜单栏图标留住面板（`pinned`）时，面板要成为键盘焦点窗口（`makeKey`），这样不用再点一下面板，Esc 就直接生效。打开设置页时已经有 `makeKey`，保持。
- 鼠标悬停预览（`preview`）时不抢键盘焦点，Esc 交给前台应用。预览本来就会在鼠标移开时收起。
- 不用全局键盘监听，不申请辅助功能权限。

## 验收
1. 单测：把 Esc 的分层判断抽成纯函数，覆盖三种情况：设置页回主页、主页收起、带修饰键不处理。
2. CI 截图不变（没有界面变化）。
3. 老板 Mac 实机走查：
   - 点图标打开面板，直接按 Esc，面板收起；
   - 点图标打开面板，进设置，按 Esc 回主页，再按 Esc 收起；
   - 悬停预览时按 Esc，前台应用照常收到，面板不受影响；
   - 收起后再点图标，停在主页。
