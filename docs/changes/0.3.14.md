# 栏量 0.3.14 契约：Gemini 凭据照 Quosparr 的做法重做

决策：PM 2026-11-26 23:16 NY。基线 master af0cd86。分支 `wip-0.3.14`。
版本号是 0.3.14，不是 0.3.3：v0.3.3 已发过，最新是 v0.3.13，版本号小了 Sparkle 不会推更新。
只参考 Quosparr 的做法，不复制它的代码（它是 AGPL 协议）。

## 0. 根因（af0cd86）
1. 从来不换新令牌：`DataSource.swift:226-232` 传的客户端 ID 和密钥是空的，`GeminiTokenStore.swift:163-167` 走不换新的那条路，`43-52` 行把 refresh_token 丢了。所以只能用 Antigravity 上次存下的访问令牌，它最长 1 小时，读到时常常只剩几分钟。
2. 读钥匙串会弹窗：`DataSource.swift:237-258` 用 `SecItemCopyMatching` 直接读，这一项的受信任程序里没有栏量。

## 1. 读官方凭据（系统层面）
- 执行 `/usr/bin/security find-generic-password -s gemini -a antigravity -w`：
  - 超时 5 秒，丢掉标准错误输出，输出只在内存里解析，不打日志；
  - 退出码 0 表示读到；
  - 退出码 44 表示 Antigravity 没登录，显示「未检测到 Antigravity 登录」，同时删除栏量的缓存；
  - 超时或其他退出码表示这次没读到，继续用缓存，下个周期再试。
- 这一项是 Antigravity 通过 `/usr/bin/security` 写入的，它本来就在受信任程序里，所以用它读不弹授权窗口。栏量自己不再调 `SecItemCopyMatching` / `SecItem*` 读这一项。
- 删除：`KeychainInteraction`、「重新授权」入口、`keychainDenied` 状态和「需要钥匙串授权才能重新读取 Gemini 登录」文案。
- 栏量**不写** Antigravity 的钥匙串项，只读。

## 2. 换新令牌
- 启用现成的 `GeminiRefresh`：用 refresh_token 加上 Antigravity 安装版 OAuth 客户端换新访问令牌。
- 访问令牌剩不到 15 分钟就换新。
- 额度接口返回 401 时，强制换新一次并重试一次；还是 401 就按「登录过期」处理。
- 换新返回 `invalid_grant`（refresh_token 失效）时，显示「Gemini 登录已过期，请打开 Antigravity 重新登录」，不弹任何窗口。之后每个周期仍先读官方凭据：refresh_token 变了（老板在 Antigravity 重新登录过）就自动恢复。
- 断网或换新时网络失败：保留上次额度，按现有规则显示旧数据提示，下个周期自动重试，不算登录过期。

## 3. 本机缓存
- 位置 `~/.lanliang/gemini-token.json`，权限 600，原子写（先写临时文件再改名）。
- 存：access_token、refresh_token、到期时间、账号邮箱。到期时间按接口返回的写，不再截短。
- 每个周期先读官方凭据：
  - refresh_token 和缓存一样，就用缓存（缓存里的访问令牌可能比官方的新）；
  - refresh_token 不一样，就用官方凭据覆盖缓存，账号、套餐和额度跟着换（Antigravity 换账号时栏量跟着换）。
- 从 0.3.13 升级上来：旧缓存里没有 refresh_token，直接丢掉，按官方凭据重建，不弹窗。

## 4. 客户端凭据
- Antigravity 安装版 OAuth 客户端的 ID 和密钥只放在 GitHub Secret 里，由 `build.sh` 注入 Info.plist，不进源码、不进仓库、不打日志、不发群。
- `release.yml` 第 91-92 行和第 105-111 行改回「必须存在」，缺了就让构建失败。
- 这推翻了之前的无密钥版（b335424、0cee5c8）。安装版应用的这一组客户端本来就随 Antigravity 安装包公开，Quosparr 也是这样做的。

## 5. 文案（只列变化）
| 状态 | 文案 |
|---|---|
| 没登录（退出码 44） | 未检测到 Antigravity 登录（保留现有） |
| refresh_token 失效 | Gemini 登录已过期，请打开 Antigravity 重新登录 |
| 额度接口失败（网络等） | Gemini 额度获取失败，栏量会自动重试 |
| 读官方凭据超时 | 暂时无法读取 Gemini 登录，栏量会自动重试 |

最长那条是「Gemini 登录已过期，请打开 Antigravity 重新登录」，比现有最长的提示短，不改面板布局。

## 6. 干净机器上的首次使用流程
1. 装好栏量并打开：全程不出现钥匙串授权窗口。
2. Antigravity 已登录：Gemini 页在第一次刷新时显示账号、套餐和额度。
3. Antigravity 没登录：显示「未检测到 Antigravity 登录」；在 Antigravity 登录后，下一个刷新周期（或手动点刷新）自动显示数据，不用重启栏量。
