# 栏量 LanLiang v0.1.2 契约（mind，2026-11-24，以 PM 20:5x NY 拍板为准）

范围只有两件，别的不加：①修 Codex 订阅有效期误判「已过期」；②菜单栏合并成唯一一个入口，默认紧凑。不做设置中心。其余行为与 0.1.0/0.1.1 契约相同。

## 1. Codex 订阅有效期
**原因**：`id_token` 里的 `chatgpt_subscription_active_until` 是令牌签发那一刻的计费周期结束日。Codex 不常换新 id_token，月度续费后这个日期就落在过去，0.1.0 直接判成「订阅已过期」（老板截图：Pro 200 显示已过期，竞品同账号显示 2026/12/12）。

**规则**（自己实现，不搬 Quosparr 代码）：
1. 套餐以 `wham/usage` 实时返回的 `plan_type` 为准；接口没成功时退回 id_token 的 `chatgpt_plan_type`。
2. 付费档 = plus、prolite/pro-lite、pro、promax/pro-max，以及含 team / business / enterprise / edu 的套餐。
3. 原始日期 `raw` 取自 id_token（缺失就取 access_token 里的同名字段）。
4. 套餐是付费档、`raw` 已过去时，按 UTC 自然月往后推，推到第一个晚于现在的日期为止。日期超出目标月的天数时取月末，比如 1/31 推成 2/28。最多推 48 次。
5. 显示：

| 情况 | 有效期行 |
|---|---|
| 付费档，日期在未来（原始或推算后） | 绿色「订阅有效期至 2026/12/12 · 剩 17 天」 |
| 付费档，剩不到 1 天 | 「订阅有效期至 2026/11/25 · 剩不到 1 天」 |
| 实时套餐是 free，且 `raw` 已过去 | 红色「订阅已过期」 |
| free 且没有日期 / API Key 账号 / 没有日期 | 不显示这一行 |
| 实时接口失败，又判断不了是不是付费档 | 日期在未来就照常显示，已过去就不显示这一行。拿不准时绝不显示「已过期」 |

- 日期用本地时区显示，格式 `yyyy/MM/dd`。剩余天数 = 向下取整（距离结束的秒数 ÷ 86400），为 0 时写「剩不到 1 天」。
- Gemini 页签不变。

## 2. 菜单栏：唯一一个入口
- 整个 app 只建 **1 个** `NSStatusItem`，Codex 和 Gemini 都放在里面。删掉 0.1.0 的分组状态项。
- **两家都登录时，上下两行**：上行 Codex，下行 Gemini。每行依次是图标、周剩余、5 小时剩余（有才显示）。
  - 图标：模板图，约 9pt 高。
  - 周剩余：比如 `74%`，9.5pt semibold，等宽数字，labelColor。
  - 5 小时剩余：比如 `64`，不带 %，8.5pt，secondaryLabelColor，只在该家有 5 小时窗口时出现。
  - 两行用同一套列对齐：图标列、周剩余列、5 小时列，数字右对齐。行距让两行在 22pt 菜单栏高度内垂直居中，不裁切。
- **只登录一家时单行，正常字号**，照 0.1.1：图标、12pt 周剩余，有 5 小时就加 10pt 浅色 5 小时剩余。
- **两家都没登录**：只显示栏量图标。
- **定宽防跳动**：按当前出现的列中最长的文案定宽。周剩余列按 `100%`，5 小时列按 `100`，只要任一行有 5 小时窗口就留出这一列。没有 5 小时窗口时不留空。
- **宽度上限**：最宽情况是两行都显示「100% 100」，状态项内容宽度不超过 75pt；两行都只有周剩余时不超过 55pt。0.1.0 的最宽情况约 200pt。
- 各状态（读取中 `…`、失败 `--`、登录过期 `--` 等）照 0.1.0 §4 状态表，只是放进对应那一行。某一家「不显示」时就退成另一家单行。
- 左键点开面板，右键菜单不变。浅色和深色菜单栏下都跟随系统颜色（0.1.1 的模板图 + labelColor）。

宽度对比 demo 用最长文案「100」测：B 方案约 73pt，就是本契约；C 方案用细进度条，约 72pt；D 方案只显示周剩余，约 53pt；E 方案一行只放每家最紧的数，约 91pt；现状约 200pt。示意图见 `docs/changes/assets/0.1.2-menubar-width.png`。选 B 的理由：和 C 一样宽，却能看到 5 小时的具体数字，满足老板「有 5 小时就显示」。

## 3. 验收
1. 老板的 Pro 200 账号：Codex 页签显示「订阅有效期至 2026/12/12 · 剩 N 天」，不再显示「已过期」。
2. 单测覆盖：付费档日期已过去会推到下一个周期末（含 1/31→2/28 和跨年）；付费档日期在未来时原样显示；free 加过去日期显示已过期；接口失败、日期已过去时不显示这一行；没有日期时不显示这一行。
3. 菜单栏只有 1 个栏量状态项（老板真机，以及 CI 截图里数状态项）。
4. 两家都登录、都有 5 小时窗口、全是 100 时，内容宽度 ≤ 75pt；两家都只有周剩余时 ≤ 55pt。单测按这两种最宽情况断言。
5. 只登录一家时是单行正常字号，宽度不为另一家留空。
6. 数字从 9% 变到 100% 时，状态项宽度不跳。
7. CI 截图：浅色和深色菜单栏各拍一套，覆盖两行（带 5 小时和不带 5 小时）和单行，文字都清楚、不发灰、不裁切。
8. 从 0.1.1 应用内升级到 0.1.2 成功，钥匙串不再弹框。
